# 轻量回归检查（人工）

改 skill 后可用下列场景快速自检，不要求自动化脚本。迷你 PRD 见 `fixtures/`。

## 1. 无图优惠券 PRD

**输入：** `fixtures/coupon-no-diagrams.md`（仅文字，无图/原型）。

**期望：**

- 不因「缺图」结论 🔴  
- D11 标注跳过；D12–D17 为「无图，基于文字推导」  
- 无独立 OOS / 验收章节 → **重要**，不单独因结构缺章节给 D1/D5 **0 分**  
- 阶段 2（完整模式）出现 D6/D9 类场景题（过期、限领后果等）  
- 题数 ≤ 15；同型异常可合并  
- 阶段 2 第一动作是点选 tool call，不是 Markdown 列表  
- 点选 options **不含**手写「其他/Other」  

## 2. 有矛盾状态机图

**输入：** PRD 写「取消订单后退券」，附图状态机无「已使用 → 未使用」且无作废说明（可用口述或自拟一张矛盾 Mermaid）。

**期望：**

- D14（或归维后的 D9 单题）记一致性/规则问题  
- 不因缺其它图额外扣分  
- 阶段 2 有取消后退券决策题，且**不**与 D9/D14 重复两道  

## 3. 仅 Figma 设计稿

**输入：** PRD + Figma 链接/导出说明，无可交互代码。

**期望：**

- 执行 D11，但不因「不是 Ant Design 代码」整单阻断  
- 缺关键页或与 PRD 矛盾 → 多为重要  
- 未提供代码原型不阻断 D2  

## 4. 工具名（Grok）

**环境：** Grok，存在 `ask_user_question`。

**期望：** 阶段 2 调用 `ask_user_question`，而不是误报「无点选工具」直接 Markdown。

## 5. 轻量模式

**输入：** 任意 PRD + 用户说「只要报告，先别问我」。

**期望：**

- 只出阶段 1 报告  
- **不**调用点选工具  
- **不**进入重生成  
- 报告注明完整模式可继续  

## 6. 点选选项契约

**任意完整模式问答。**

**期望：**

- Claude/Grok：options 2–4 个实质方案，无「其他」label  
- Codex：2–3 个实质方案；推荐项 `(Recommended)`；无 Other  
- Markdown 降级才允许「D. 其他」  

## 7. 加载预算（抽查 transcript）

**期望：** 无图场景下阶段 1 **未**通读全部 6 个图 framework 全文；有状态机图时才读 `state-machine-review-framework.md`。
