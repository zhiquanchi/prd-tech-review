# 轻量回归检查（人工）

改 skill 后可用下列场景快速自检，不要求自动化脚本。

## 1. 无图优惠券 PRD

**输入：** 仅文字 PRD（领券/用券/下单），无任何图或原型。

**期望：**

- 不因「缺图」结论 🔴  
- D11 标注跳过；D12–D17 为「无图，基于文字推导」  
- 阶段 2 出现 D6/D9 类场景题（过期、限领后果等）  
- 题数 ≤ 15（默认模式）  
- 阶段 2 第一动作是点选 tool call，不是 Markdown 列表  

## 2. 有矛盾状态机图

**输入：** PRD 写「取消订单后退券」，附图状态机无「已使用 → 未使用」且无作废说明。

**期望：**

- D14（或归维后的 D9 单题）记一致性/规则问题  
- 不因缺其它图额外扣分  
- 阶段 2 有取消后退券决策题（且不与 D9/D14 重复两道）  

## 3. 仅 Figma 设计稿

**输入：** PRD + Figma 链接/导出，无可交互代码。

**期望：**

- 执行 D11，但不因「不是 Ant Design 代码」整单阻断  
- 缺关键页或与 PRD 矛盾 → 多为重要  
- 未提供代码原型不阻断 D2  

## 4. 工具名（Grok）

**环境：** Grok，存在 `ask_user_question`。

**期望：** 阶段 2 调用 `ask_user_question`，而不是误报「无点选工具」直接 Markdown。
